# MAC and IP Address
## Media Access Control (MAC) Adress
### What is MAC Address
It is a unique identifier assigned to a network interface on device such as a laptop, router etc. It used to identify devices on a local network. 

It looks like: **A4:5E:60:C2:1B:9F**

### How MAC Adress work
Imagine your laptop wants to communicate with a printer connected to the same wifi network.
1. The laptop determines the printer's IP address.
2. If necessary, it uses ARP (Address Resolution Protocol) to discover the printer's MAC address on an IPv4 local network.
3. The laptop sends a network frame addressed to the printer's MAC address.
4. The network equipment forwards the frame toward the printer.

## Internet Protocol (IP)
### What is IP
It is a set of rules that allows devices to address and send data to each other across networks, including the internet.

We have two type ID Address: Public and private.

**Public IP Address**: Communication within private networks.
**Private IP Address**: Communication across the public internet.

We have two main version of IP Address. They look like:

IPv4:**192.168.1.14**
IPv6:**2001:db8::1**
