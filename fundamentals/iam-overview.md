## What is IAM 
Regardless of where employees are working, they need to access their organization's resource like app, file and data. The traditional wat of doing things was to have the most of workers work on-site where company resource were kept behind a firewall.

However, nowadays hybrid work is more comman than ever and employees need secure access to resource whether they are working on-site ore remotely. This is where identity and access management (IAM) comes in. The organization's IT department needs to control what user can and can not access so that sensitive data.

With an IAM system, the organization can quickly and accurately verify a person's identity and give necessary permission.

## How IAM works
1. **Request:** A user or service tries to log in or access a specific resource (like a database or cloud folder).
2. **Verify (Authentication):** The IAM system checks the user's name and password or MFA token against a directory to confirm identity.
3. **Check Permissions (Authorization):** The system reviews the user's assigned role or security policy via tools like IAM Overview to see if they have the right to access that specific item.
4. **Grant or Deny:** If allowed, the door opens; if not, the system blocks access and throws an error message (like "Access Denied").
